## Programmatic access

Agents and automated tools can read this blog as clean Markdown, without the HTML chrome:

- [llms.txt]({{ "llms.txt" | absURL }}): this index, linking to the Markdown version of every article.
- Every article and page URL has a Markdown twin: replace the trailing `/` with `.md` (e.g. `/blog/2026/08/03/my-post/` becomes `/blog/2026/08/03/my-post.md`). Requests with `Accept: text/markdown` to the article URL get the Markdown directly, and each HTML page links to it with `<link rel="alternate" type="text/markdown">`.
