Shadleaf 1.0: UI components for Thymeleaf

If you build with React or Angular, you pick a component library and you have buttons, dialogs, date pickers and tables ready to go. With Thymeleaf, you end up writing all of that yourself, in every project again.

Shadleaf fixes that. It is an open-source library of accessible, themeable components, inspired by shadcn/ui and packaged as a Spring Boot starter. You use the components as custom tags in your templates:

<sl:button variant="destructive" hx-delete="/orders/42">
  <sl:slot name="icon-start"><sl:icon name="trash"/></sl:slot>
  Delete order
</sl:button>

What is in 1.0:

•  About 50 components, from buttons and inputs to dialogs, comboboxes, date pickers, tables, charts and a full application shell
•  Themed with shadcn's CSS variables, in light and dark mode
•  Works with htmx and Alpine.js, also under a strict Content-Security-Policy
•  Checked props: a typo like variant="destructve" fails with a clear message
•  Plain Maven build is enough: the jar ships compiled CSS and JavaScript
•  Code completion in IntelliJ IDEA, and docs as Markdown for coding agents
