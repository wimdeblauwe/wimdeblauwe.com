The most important changes:

•  Spring Boot 4.1.1 for all the code in the book
•  Java 25, the current LTS version
•  Vite with vite-plugin-spring-boot for a fast live reload of templates, CSS and JavaScript
•  Tailwind CSS 4 and Tailwind Plus Elements for interactive components
•  Cally replaces the unmaintained Duet Date Picker
•  Testcontainers with @ServiceConnection instead of the JDBC URL
•  Cypress 16.1.0 for the end-to-end tests
